# M10 本地知识平台

M10 把现有内存知识样例改造成可维护、可授权、可回查的本地知识系统。它负责文档导入、
版本、权限、索引、检索和稳定引用；不接入真实企业知识库，不处理图片/OCR，也不把知识
正文写入 LangGraph Checkpoint。

## 状态与责任边界

- PostgreSQL 保存文档、版本、ACL、生命周期和索引任务，是知识事实源。
- pgvector 与关键词索引是可重建投影；Redis 只能做短时缓存，丢失后必须能从 PostgreSQL
  重建。
- `packages/retrieval` 负责混合排序、去重、阈值和引用复验，不拥有租户或授权决定。
- Knowledge MCP 只从可信 Gateway 接收请求，先完成 SecurityContext、用途、租户、ACL、
  分级和有效期过滤，再调用检索 Port。
- LangGraph 只保存查询意图、稳定引用和安全摘要。原始正文、向量、候选列表和 Provider
  Session 不进入业务状态。
- Web 管理动作经过可信 API、策略和审计边界；模型不能导入、修改、删除或授权文档。

## 文档与版本

内部领域模型至少包含：

- `document_id`、`version_id`、tenant、来源、标题和章节；
- 内容 Hash、规范化文本 Hash、数据分级、用途、ACL 和来源可信度；
- 生效、过期、撤销、删除和索引状态；
- 创建者、审批/策略绑定、幂等键和审计引用。

每次内容或授权变化都产生新版本。旧版本不可被原地改写；删除先停止候选资格，再以受控
任务清理可重建索引。稳定引用绑定 `document_id + version_id + section + content_hash`，新
版本不能让旧引用悄悄指向新内容。

## 导入与索引

本地导入按固定顺序执行：

1. 验证可信身份、租户、用途、策略与幂等键。
2. 限制文件类型、大小和字符编码；M10 只接受受控文本格式。
3. 运行 Secret/DLP 与 Prompt Injection 检查；危险内容隔离，不进入可检索索引。
4. 规范化文本、计算 Hash、切分稳定章节和片段。
5. 原子写入文档版本与 Outbox；索引 Worker 幂等消费。
6. 写入关键词索引和 pgvector，记录索引版本与算法版本。
7. 回读文档、ACL、片段数量和索引摘要，成功后才标记可检索。

本地向量默认使用确定性的离线 Embedding Port 实现，保证测试和演示不依赖在线模型；
未来可替换为模型 Embedding Adapter，但不得改变授权、引用和事实状态。Migration 必须线性、
可回滚；索引可重建，文档事实不可通过重建覆盖。

## 检索管线

1. 可信入口重算 tenant、主体、用途、分级上限和 SecurityContext Hash。
2. 数据层先应用 tenant、ACL、用途、分级、生效、过期和撤销条件。未授权文档不得进入
   候选集合，不能先取内容再在应用层过滤。
3. 对授权候选计算关键词分数和向量分数，按版本化权重合并。
4. 按文档版本去重、阈值过滤，并使用稳定键打破同分排序。
5. Retrieval Engine 重新验证候选元数据、内容 Hash 和引用完整性。
6. Knowledge MCP 只返回 `knowledge.search.v1` 已允许的安全字段：来源引用、版本、章节、
   脱敏摘要、内容 Hash 和分级。
7. 没有有效证据时明确返回无结果；Agent 不得用模型常识伪造企业知识结论。

混合检索的权重、阈值、分词、Embedding 和重排版本进入诊断证据。相同数据、配置和查询
必须得到确定顺序；超时、索引缺失、引用漂移和安全校验失败都返回稳定错误码。

## 管理与诊断

本地 Web 提供文档列表、版本、导入/更新/撤销、索引状态、检索诊断和稳定引用回查。
普通用户只查看有权限的安全投影；管理员写操作仍受策略、职责分离、幂等与审计控制。
诊断页面可以显示分数、规则版本和过滤原因，但不显示未授权标题、正文、向量、原始 Prompt、
Secret 或隐藏思维链。

## 安全与恢复

- 跨租户候选、读取、写入和引用解析成功数必须为 0。
- 恶意文档不能通过 Prompt Injection 影响工具、审批、授权或任务终态。
- Import、Index、Retire 和 Rebuild 均可重试；同幂等键不同摘要必须冲突。
- Worker 重启、Redis 清空、索引任务重复投递和 Migration 中断后可以从事实表恢复。
- 引用解析使用精确版本；过期、撤销、Hash 不符或版本不存在时失败关闭。
- Trace 可采样；导入、权限变化、删除和安全拒绝必须产生不可采样的 Audit/Security Event。

## M10 完成边界

- 本地文档可以导入、更新、撤销、删除和重建索引。
- pgvector 与关键词混合检索可解释、可回放，并在检索前完成授权过滤。
- `knowledge.search.v1` Schema Hash 保持不变；内部排序和诊断字段不外泄到工具契约。
- 固定 156 条 Case 不缩分母，只为真实接通的 M10 能力注册独立执行器。
- 不宣称企业知识库 Connector、生产级向量集群、OCR/多模态或云端高可用。
